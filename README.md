# AssassinNote

어쌔신 크리드 시리즈를 연표와 위키로 정리하는 팬 노트입니다.

- 연표와 위키 내용은 플레이 영상에서 직접 확인한 것만 담고, 모든 항목에 영상 출처(몇 분 몇 초)를 링크합니다.
- 영상에서 연도가 확인되지 않은 사건은 "(추정)"으로 표시합니다.

## 사용 방법

설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

- `js/data.js`: 연표 사건과 위키 문서 데이터
- `js/app.js`: 화면과 기능
- `css/style.css`: 디자인

앱 화면에서 편집한 내용은 그 브라우저에만 저장됩니다. 다른 곳으로 옮기려면 데이터 메뉴의 JSON 내보내기를 쓰세요.

## 안내

비공식 팬 프로젝트입니다. 어쌔신 크리드는 Ubisoft의 상표입니다.
